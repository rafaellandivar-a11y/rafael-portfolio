Windows Server 2025 Installation

Dokumentation eines Lernprojekts zur Installation von Windows Server 2025 in einer virtuellen Testumgebung.

Ziel des Projekts

Ziel dieses Projekts war es, die Installation von Windows Server 2025 in einer virtuellen Maschine praktisch nachzuvollziehen und die einzelnen Schritte verständlich zu dokumentieren.

Der Fokus lag nicht nur auf der Installation selbst, sondern auch auf sauberer Vorbereitung, grundlegender Konfiguration und technischer Dokumentation.

Testumgebung

  • Virtualisierung: Oracle VirtualBox
  • Gastbetriebssystem: Windows Server 2025
  • Netzwerk: NAT / internes Netzwerk je nach Übung
  • Speicher: virtuelle Festplatte mit manueller Partitionierung
  • Ziel: Aufbau einer Lernumgebung für Systemintegration

Durchgeführte Schritte

  1. Erstellung einer neuen virtuellen Maschine in VirtualBox
  2. Zuweisung von Arbeitsspeicher, CPU und virtueller Festplatte
  3. Einbindung des Windows Server 2025 Installationsmediums
  4. Start der virtuellen Maschine
  5. Auswahl von Sprache, Tastatur und Installationsoption
  6. Einrichtung der Festplatte und Partitionierung
  7. Installation des Betriebssystems
  8. Erste Anmeldung und grundlegende Kontrolle der Installation

Was ich dabei gelernt habe

  • Grundlagen der Serverinstallation in einer virtuellen Umgebung
  • Unterschied zwischen virtueller Maschine und physischem System
  • Bedeutung von sauberer Vorbereitung vor der Installation
  • Grundlagen der Partitionierung während der Installation
  • Dokumentation technischer Arbeitsschritte

Bezug zur Systemintegration

Dieses Projekt ist ein grundlegender Einstieg in typische Aufgaben der Systemintegration. Dazu gehören das Einrichten von Systemen, das Arbeiten mit virtuellen Umgebungen, die Vorbereitung von Testsystemen und die nachvollziehbare Dokumentation technischer Prozesse.

Status

Dieses Projekt ist ein Lernprojekt und wird weiter ausgebaut. Geplant sind ergänzende Schritte wie Netzwerkkonfiguration, Benutzerverwaltung, Rolleninstallation und weitere Server-Grundlagen.
