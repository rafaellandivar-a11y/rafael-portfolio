# Rafael Landívar – Portfolio

Dies ist mein persönliches Portfolio als Junior Webentwickler.

Der Schwerpunkt liegt auf einfachen, verständlichen Webprojekten mit HTML, CSS und JavaScript.  
Mein beruflicher Hintergrund liegt im Recruiting, Onboarding und in der Prozessorganisation. Dieses Portfolio zeigt, wie ich diese Erfahrung mit Webentwicklung verbinde.

## Projekte

### 1. Onboarding-Checkliste
Eine interaktive Checkliste für neue Mitarbeitende.

**Funktionen:**
- Aufgaben abhaken
- Fortschritt anzeigen
- Speicherung mit localStorage

**Technologien:** HTML, CSS, JavaScript

### 2. Recruiting Landing Page
Eine Informationsseite für Bewerberinnen und Bewerber mit Prozessübersicht, FAQ-Bereich und Formularprüfung.

**Technologien:** HTML, CSS, JavaScript

### 3. Mini Recruiting Dashboard
Ein kleines Dashboard mit Beispieldaten, Kennzahlen und Filterfunktion.

**Technologien:** HTML, CSS, JavaScript

## Ziel

Das Portfolio dient dazu, meine praktischen Kenntnisse sichtbar zu machen und meine Entwicklung im Bereich Webentwicklung zu dokumentieren.
