# Rafael Landívar – IT-Portfolio

Dies ist mein persönliches IT-Portfolio im Rahmen meiner Weiterentwicklung zum **Fachinformatiker für Systemintegration**.

Der Schwerpunkt dieses Portfolios liegt auf praktischen Lernprojekten aus den Bereichen:

* IT-Systemintegration
* Virtualisierung
* Windows Server
* Netzwerkgrundlagen
* Linux-Grundlagen
* technische Dokumentation
* IT-Support-Orientierung

Ergänzend enthält das Portfolio auch kleinere Web- und Digitalprojekte, die meine digitale Affinität und meine praktische Arbeitsweise zeigen.

## Systemintegration-Lab

### Windows Server 2025 Installation

Dokumentation einer Windows-Server-Installation in einer virtuellen Testumgebung.

**Schwerpunkte:**

* VirtualBox
* Windows Server 2025
* Installation
* Partitionierung
* technische Dokumentation

### VirtualBox Netzwerk-Labor

Lernprojekt zu Netzwerkeinstellungen in VirtualBox, insbesondere NAT und internes Netzwerk.

**Schwerpunkte:**

* VirtualBox
* NAT
* internes Netzwerk
* virtuelle Netzwerkadapter
* isolierte Testumgebungen

### Linux-Grundlagen

Sammlung grundlegender Linux-Befehle und Übungen zur Arbeit mit Terminal, Dateistruktur, Benutzerrechten und einfacher Systemverwaltung.

**Schwerpunkte:**

* Linux Terminal
* Dateisystem
* Benutzerrechte
* Systeminformationen
* Netzwerkgrundlagen
